# 学习笔记编修规范

这份规范用于后续修订，避免笔记继续变成“内容很多但条件散落”的摘录。

## 每个重点知识单元

1. **定义与符号**：变量所在空间、形状、下标含义及必要假设。
2. **核心公式或定理**：写出结论，并紧邻标注光滑性、凸性、噪声、步长或维度条件。
3. **推导或数值例子**：关键结论至少有一个可检查的中间步骤或数值实例。
4. **常见误解与反例**：说明容易混淆的结论、缺失条件或错误矩阵维度。
5. **原始资料定位**：给出课程 PDF 页码；必要时链接原论文或项目。

## 表达约定

- 公式使用 Obsidian 与 GitHub 均可解析的 `$...$`、`$$...$$`。
- 避免 `\operatorname`；使用 `\mathrm{...}` 等兼容宏。
- 矩阵换行独立书写，不使用难读的单行 `\\`。
- 新概念先声明维度，再相乘或求逆。
- 收敛率必须同时说明误差量（目标值、距离或梯度范数）与所用步长/平均方式。
- “固定步长”结论要区分精确收敛与噪声邻域。

## 自动化检查

```bash
python3 tools/check_notes.py
python3 tools/test_math_notes.py
```

前者负责文件、链接、公式语法、课程标签和 SHA-256；后者负责高风险公式的数值回归。新增公式若影响强凸 GD、SGD 噪声、零阶估计、投影维度等主题，应同时扩展测试。
